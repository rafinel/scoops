## Lessons learned

- Preflight warnings from the existing workspace do not invalidate a passing Playwright health check when they are classified and no browser, console, network or assertion failure is observed. Source finding: `FND-001`. Authority disposition: no documentation change; already-covered environment behavior.
- Cross-field product invariants must be enforced both in the owning use case and at the UI affordance. Source finding: `FND-027`. Authority disposition: `documentation/prds/mrp.md` `REQ-01` already requires Manufacturable to lock Single stock with an explanation; no PRD, Architecture, Design or Rule Pack update was needed.
- Behavior-owning hooks need direct coverage in addition to component tests that mock them. Source evidence: `EV-20`. Authority disposition: all eight Settings hooks now have colocated `renderHook` tests covering state transitions, validation, retries, guards and action outcomes.
- Unit changes must preserve numeric facts when adopting a new unit. Source finding: `FND-028`. Authority disposition: the MRP PRD and Settings Spec revision 3 now define unit relabeling without multiplication, division, rounding, density assumptions or conversion factors.
- Recovery links for reverse dependencies must filter by the product being removed, while preserving the dependent record as the displayed context. Source finding: `FND-029`. Authority disposition: feature-local navigation correction; existing REST and Core list-filter contracts already define `usedAsAccompanimentId`, so no authority change was needed.
- Shared registration payload changes require a full mocked route-suite rerun and updates to every affected fixture/assertion, not only the new feature route. Source finding: `FND-030`. Authority disposition: no documentation change; `documentation/tooling.md` and the Web routing Rule already require the full `tests/routes` suite, so this is an execution correction rather than a missing repository rule.
- A passing feature route gate can coexist with unrelated serial browser-harness flakiness in a broad route matrix. Source finding: `FND-031`. Authority disposition: no documentation change; the corrected exact matrix remains recorded in `EV-26`, the clean rerun is classified by its unrelated failures in `EV-28`, and the affected Pricing route is independently green in `EV-29`.
- Integration fixtures for event-producing mutations must replace external brokers with deterministic test doubles when CI does not provide delivery credentials. Source finding: `FND-032`. Authority disposition: no documentation change; the existing Identity fixture already demonstrates the local pattern, and the correction is scoped to the MRP fixture.
