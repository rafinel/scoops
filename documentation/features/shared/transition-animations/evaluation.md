## Lessons learned

- Route-transition browser evidence is most reliable when the test holds a real
  application navigation boundary, rather than sleeping or adding a production
  loader solely for evidence. Authority disposition: `No change` — the existing
  routing and Playwright rules already require deterministic, user-visible route
  validation; this implementation keeps the delay seam test-only.
- Complexity baselines must be refreshed after intentional ownership refactors
  that shift function line ranges. Authority disposition: `No change` — the
  repository tooling already documents the generated-baseline workflow and the
  refreshed artifact is recorded as Orchestrator-owned evidence.
- The shared UI rule clarification was inherited uncommitted work during this
  delivery. Authority disposition: `Excluded` — it is not included in the
  delivery commit or represented as a feature behavior change; the implementation
  itself conforms to the applicable rule.
