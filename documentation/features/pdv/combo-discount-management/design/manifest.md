## Allowed deviations and comparison rules

- Use repository CSS/Tailwind tokens and shared components; the hex values and Manrope variable in the Pencil document are mapping evidence, not permission to add parallel hardcoded values.
- Follow the current repository dialog-header Rule when it conflicts with `OjX10`; preserve the reference's information hierarchy, available/unavailable choices, density, and semantic colors.
- Runtime fixtures may use different names and monetary values, but information order, labels, status semantics, calculations, and action hierarchy must remain equivalent.
- Only the five saved references are visual comparison targets; other implemented states are validated behaviorally against the Spec and repository design rules.
- Fresh Playwright CLI screenshots captured during implementation are transient validation artifacts recorded in `../evaluation.md`; they do not replace this saved bundle.
