## Lessons learned

- Inventory every contracted behavior hook against the implementation coverage gate before source edits. Existing authority already states this requirement; no Rule change needed.
- An unset DISPLAY does not establish that WSL lacks a graphical host. Check existing WSLg sockets and connectivity before declaring a host unavailable. DISPLAY=:0 restored headed launch here. Native printing still requires its own evidence; no authority change needed.
